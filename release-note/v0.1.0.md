# OpenAuthSter WebUI v0.1.0

**Release Date:** February 11, 2026

🎉 **Initial Release** - Introducing OpenAuthSter WebUI, the management dashboard for your OpenAuthSter authentication system. Built on Cloudflare Pages, it provides an intuitive interface to configure, customize, and manage your multi-tenant authentication infrastructure.

## Overview

OpenAuthSter WebUI is a production-ready management dashboard that empowers you to configure authentication projects, customize themes, manage OAuth providers, and monitor user activity—all from a beautiful, responsive web interface.

## ✨ Key Features

### Project Management

- **Create Projects:** Initialize new authentication projects with unique configurations
- **Project Dashboard:** Centralized view of all your authentication projects
- **Custom Domains:** Automatic subdomain creation for each project via Cloudflare Workers
- **Project Templates:** Copy configurations from existing projects for faster setup
- **Invite System:** Generate and manage invite links for controlled project access
- **Project Settings:** Configure project-specific authentication options and behaviors

### Theme Customization

- **Visual Theme Editor:** Customize authentication UI appearance per project
- **Live Preview:** See theme changes in real-time
- **Theme Management:** Create, edit, and delete custom themes
- **Brand Consistency:** Match authentication pages to your application's design
- **CSS Customization:** Full control over authentication page styling
- **Theme Templates:** Reusable themes across multiple projects

### Email Template Management

- **Custom Email Templates:** Design personalized verification emails
- **Mustache Templating:** Dynamic content with variable interpolation
- **Template Library:** Manage multiple email templates
- **Email Preview:** Visual preview before deployment
- **Subject & Body Editor:** Full control over email content
- **Code Editor Integration:** Monaco Editor for template editing

### OAuth Provider Configuration

- **Provider Setup:** Configure OAuth/OIDC providers through intuitive forms
- **Supported Providers:**
  - Google OAuth
  - GitHub OAuth
  - Microsoft OAuth
  - Apple OAuth & OIDC
  - Slack OAuth
  - AWS Cognito
  - Keycloak
  - Generic OAuth2/OIDC
- **Password Authentication:** Configure email/password login
- **Email Code (Magic Links):** Setup passwordless authentication
- **Provider Management:** Add, edit, remove providers per project
- **Credential Security:** Secure storage of OAuth client secrets

### User Management

- **User Directory:** View all users across your projects
- **User Details:** Inspect user profiles and authentication data
- **Session Management:** Monitor active user sessions
- **User Activity:** Track user authentication events

### Activity & Monitoring

- **Activity Logs:** Comprehensive audit trail of system events
- **Project Activity:** Per-project activity tracking
- **Real-time Updates:** Monitor authentication events as they happen
- **Event Filtering:** Search and filter activity logs

### Developer Experience

- **Monaco Editor:** Professional code editing for templates and themes
- **TypeScript Support:** Fully typed codebase with shared types
- **React Integration:** Modern React 19 with hooks
- **Hot Reload:** Fast development with Frame Master
- **Responsive Design:** Works seamlessly on desktop and mobile
- **Tailwind CSS:** Utility-first styling with custom configuration

### Cloudflare Integration

- **Workers API Integration:** Manage Workers and domains programmatically
- **Custom Domain Creation:** Automatic subdomain provisioning
- **D1 Database Access:** Direct database integration with issuer
- **Pages Functions:** Server-side API routes on the edge
- **Zero Cold Starts:** Instant response times globally

## 🚀 Getting Started

### Prerequisites

- OpenAuthSter Issuer deployed and running
- Cloudflare account with Pages and Workers access
- Cloudflare API token with Workers management permissions
- Bun.js or Node.js for development

### Quick Deploy

```bash
# Install dependencies
bun install

# Configure wrangler.jsonc with your settings

# Deploy to Cloudflare Pages
# (Connect GitHub repo in Cloudflare Dashboard)
```

### Local Development

```bash
# Install dependencies
bun install

# Create .env file with configuration

# Start dev server
bun dev
```

For detailed setup instructions, see the [README](../README.md).

## 🔧 Configuration

### Required Environment Variables

- `PUBLIC_ISSUER` - OpenAuthSter issuer URL
- `PUBLIC_REDIRECT_URI` - WebUI callback URL
- `CLOUDFLARE_API_TOKEN` - API token for Workers management
- `CLOUDFLARE_ACCOUNT_ID` - Cloudflare account ID
- `CLOUDFLARE_AUTH_DOMAIN_ZONE_ID` - Zone ID for auth domain
- `CLOUDFLARE_WORKER_SERVICE_NAME` - Issuer Worker name

### Database Binding

- `PROJECT_DB` - D1 database binding (shared with issuer)

## 📝 Known Limitations

- **Work in Progress:** Active development - please report issues
- **Admin Access:** Only users listed in `WEBUI_ADMIN_EMAILS` can access the dashboard
- **No CLI:** Project management currently requires web interface
- **Single Issuer:** WebUI manages one issuer deployment at a time
- **Custom Domain Required:** Cloudflare zone access needed for subdomain creation
