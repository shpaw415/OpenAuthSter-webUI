# Release Notes - v0.2.0

**Release Date:** February 14, 2026

## 🔄 Compatibility Update

This release updates OpenAuthster WebUI to maintain compatibility with:

- `openauthster-shared` v0.2.0
- `OpenAuthSter-issuer` v0.2.0

## ✨ What's New

- Full support for custom subject schemas introduced in shared types v0.2.0
- Enhanced user management interface for new admin features
- Improved error messaging aligned with new error handling
- Updated token verification flows

## 📦 Updates

- Updated dependencies to use `openauthster-shared@0.2.0`
- Aligned API calls with new user management endpoints
- Enhanced session management UI

## 🚀 Upgrade Notes

This is a compatibility release. Ensure all OpenAuthster components are updated to v0.2.0 for full functionality.

---

For detailed changes in the underlying client library, see [openauthster-shared v0.2.0 release notes](../../openauth-webui-shared-types/release-notes/v0.2.0.md).
