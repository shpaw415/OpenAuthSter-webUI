# Release Notes - v0.3.0

**Release Date:** February 20, 2026

## 🔄 Compatibility Update

This release updates OpenAuthster WebUI to maintain compatibility with:

- `openauthster-shared` v0.3.0
- `OpenAuthSter-issuer` v0.3.0

## 🎉 New Features

### Webhook Management

Added comprehensive webhook configuration and management interface:

- **Webhook Dashboard** - Visual interface for managing webhook endpoints
  - Register and configure webhook URLs for real-time event notifications
- **Event Subscription Management** - Control which events trigger webhooks
  - Granular event selection (user register, user login, etc.)
  - Multiple webhook support with different event filters
  - Secure webhook authentication configuration

### Version Monitoring

Implemented automatic version checking for OpenAuthster components:

- **Issuer Version Monitoring** - Real-time detection of issuer updates
  - Automatic polling of issuer `/version` endpoint
  - Visual notifications when new issuer versions are available
  - Helps admins stay current with backend updates
- **WebUI Self-Update Detection** - Track WebUI releases
  - Automatic detection of available WebUI updates
  - Update notifications in the admin interface
  - Seamless upgrade prompts for better maintainability

### UI/UX Improvements

#### Redesigned Navigation Menu

Complete overhaul of the navigation system for improved user experience:

- **Modern Menu Design** - Clean, intuitive navigation structure
  - Streamlined menu hierarchy for faster navigation
  - Improved visual hierarchy and grouping of related features
  - Enhanced mobile responsiveness
  - Better accessibility with keyboard navigation support
- **User-Friendly Layout** - Optimized for common workflows
  - Quick access to frequently used features
  - Contextual menu items based on user permissions
  - Visual indicators for active sections

## 📦 Updates

- Updated dependencies to use `openauthster-shared@0.3.0`
- Integrated webhook API endpoints from issuer v0.3.0
- Enhanced UI components with modern design patterns
- Improved CORS handling for version checking

## 🚀 Upgrade Notes

This release introduces new webhook capabilities that work seamlessly with OpenAuthster Issuer v0.3.0. Ensure your issuer is upgraded to v0.3.0 to utilize webhook features.
