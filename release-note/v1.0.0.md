# Release Notes - v1.0.0

**Release Date:** April 2, 2026

## Overview

`v1.0.0` is the first major WebUI release since `v0.3.0`. The focus of this release is making OpenAuth WebUI ready for day-to-day multi-tenant administration: stronger ownership boundaries, collaborator and invite flows, a redesigned dashboard experience, improved provider configuration, and better support for self-hosted deployments.

## Breaking Changes

- No in-place update path is supported for this release.
- Upgrading from `v0.3.0` to `v1.0.0` requires a clean install and a fresh deployment.

## Major Highlights

### Dashboard and Navigation Overhaul

The application layout was reworked around a unified dashboard experience.

- Consolidated the main admin surfaces under the dashboard for projects, activity, configurations, users, notifications, templates, and themes.
- Refreshed navigation, page structure, and icon usage to make larger installations easier to operate.
- Added more consistent in-app feedback with snackbar handling cleanup and improved error boundaries.

### Collaboration, Ownership, and Invite Flows

This release significantly expands team-oriented workflows.

- Added ownership enforcement across project, template, and theme endpoints.
- Introduced collaborator management for project resources.
- Completed invite setup for sharing and access workflows, including accept, manage, revoke, and invite-link updates.
- Improved shared access handling for collaborative administration.

### Project Isolation and Multi-Tenant Administration

The WebUI now does a better job of treating projects as isolated working units.

- Added group access and project ownership support to core management flows.
- Improved project management and dashboard data handling for multi-project environments.
- Expanded project data handling and sandbox-related workflows for safer editing and iteration.
- Refined project setup behavior, including website URL handling, origin updates, and endpoint configuration fixes.

### Provider and Template Management

Provider configuration and content editing received substantial work in this cycle.

- Added richer provider scope handling in the provider configuration UI.
- Updated provider navigation and documentation, including clearer Apple OAuth and Apple OIDC coverage.
- Improved template editing flows with a function editor modal and a new Mustache guide for template authors.
- Continued refinement of copy-template, email-template, and UI-template management flows.

### Self-Hosting and Deployment Improvements

Several changes in this release focus on deployment flexibility and operational reliability.

- Added self-hosted environment handling and fixed endpoint resolution issues in self-hosted setups.
- Hardened Cloudflare build and deployment behavior, including handling around `CF_ACCOUNT_ID` collisions.
- Updated dependencies and shared library integration to align the WebUI with the `v1.0.0` release.
- Removed outdated imports and completed general cleanup for the `1.0.0` release.

## Developer Experience and Quality

- Adopted Biome formatting and cleanup across the codebase.
- Normalized several hooks and data-loading paths used by the dashboard and editing flows.
- Improved stability in notifications, user management, and activity/log handling.
- Expanded tests around Cloudflare and core application behavior.

## Upgrade Notes

- There is no supported in-place upgrade from `v0.3.0`. Deploy `v1.0.0` as a clean install.
- If you are moving from `v0.3.0`, review any bookmarked routes or internal links that relied on the older top-level page structure. The UI is now centered around the dashboard layout.
- Collaboration and ownership behavior is stricter in this release. Make sure your backend and shared package versions are aligned with the `v1.0.0` release.
- Review deployment configuration for self-hosted installations and Cloudflare environments before promoting to production.
