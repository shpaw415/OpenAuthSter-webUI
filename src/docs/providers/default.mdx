# Provider Setup

Configure this OAuth provider for authentication.

## Setup Steps

1. Register your application with the OAuth provider
2. Configure the **Client ID** and **Client Secret**
3. Set up the **redirect URI** in your provider's settings
4. Configure any additional **scopes** as needed

## Configuration Fields

| Field                       | Required | Description                                          |
| --------------------------- | -------- | ---------------------------------------------------- |
| Client ID                   | Yes      | The OAuth client ID from your provider               |
| Client Secret               | Yes      | The OAuth client secret from your provider           |
| Scopes                      | No       | Additional OAuth scopes to request                   |
| PKCE                        | No       | Enable PKCE for enhanced security                    |
| Additional Query Parameters | No       | Extra parameters to include in the authorization URL |

## PKCE Support

PKCE (Proof Key for Code Exchange) is an extension to the OAuth 2.0 authorization code flow that provides enhanced security. Enable it if your provider supports it.

## Additional Query Parameters

Some providers support additional query parameters in the authorization URL. Use the key-value editor to add custom parameters as needed.

## Common Scopes

- `email` - Access to user's email address
- `profile` - Access to user's basic profile information
- `openid` - Required for OpenID Connect providers

## Redirect URI

Make sure to configure your redirect URI correctly in the provider's settings. The redirect URI should match exactly what is configured in your application.
