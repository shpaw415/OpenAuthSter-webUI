# Discord OAuth2 Setup

Configure Discord OAuth2 to allow users to sign in with their Discord accounts.

## Setup Steps

1. Go to the [Discord Developer Portal](https://discord.com/developers/applications)
2. Click **New Application** and give it a name
3. Navigate to **OAuth2** section in the sidebar
4. Copy the **Client ID**
5. Click **Reset Secret** to generate and copy the **Client Secret**
6. Add your redirect URI under **Redirects**

## Configuration Fields

| Field                       | Required | Description                                          |
| --------------------------- | -------- | ---------------------------------------------------- |
| Client ID                   | Yes      | The OAuth 2.0 client ID from Discord                 |
| Client Secret               | Yes      | The OAuth 2.0 client secret from Discord             |
| Scopes                      | No       | Additional OAuth scopes                              |
| PKCE                        | No       | Enable PKCE for enhanced security                    |
| Additional Query Parameters | No       | Extra parameters to include in the authorization URL |

## PKCE Support

Discord supports PKCE (Proof Key for Code Exchange). Enable it for enhanced security in your OAuth flow.

## Additional Query Parameters

Common parameters you might want to add:

| Parameter              | Description                                        |
| ---------------------- | -------------------------------------------------- |
| `prompt`               | Control consent screen (`none` or `consent`)       |
| `guild_id`             | Pre-select a guild for the bot authorization       |
| `disable_guild_select` | Prevent users from changing the pre-selected guild |

## Recommended Scopes

- `identify` - Access to user's username, avatar, etc.
- `email` - Access to user's email address
