# GitHub OAuth Setup

Configure GitHub OAuth to allow users to sign in with their GitHub accounts.

## Setup Steps

1. Go to [GitHub Settings](https://github.com/settings/developers) > **Developer settings** > **OAuth Apps**
2. Click **New OAuth App**
3. Fill in your application details:
   - **Application name**: Your app's name
   - **Homepage URL**: Your application's URL
   - **Authorization callback URL**: Your redirect URI (e.g., `https://your-domain.com/github/callback`)
4. Click **Register application**
5. Copy the **Client ID**
6. Click **Generate a new client secret** and copy it

## Configuration Fields

| Field                       | Required | Description                                          |
| --------------------------- | -------- | ---------------------------------------------------- |
| Client ID                   | Yes      | The OAuth client ID from GitHub                      |
| Client Secret               | Yes      | The OAuth client secret from GitHub                  |
| Scopes                      | No       | Additional OAuth scopes to request (default: email)  |
| PKCE                        | No       | Enable PKCE for enhanced security                    |
| Additional Query Parameters | No       | Extra parameters to include in the authorization URL |

## PKCE Support

GitHub supports PKCE (Proof Key for Code Exchange). Enable it for enhanced protection against authorization code interception attacks.

## Additional Query Parameters

Common parameters you might want to add:

| Parameter      | Description                               |
| -------------- | ----------------------------------------- |
| `login`        | Suggest a specific account to sign in     |
| `allow_signup` | Whether to allow sign-up (`true`/`false`) |

## Recommended Scopes

- `user:email` - Access to user's email addresses
- `read:user` - Access to user's profile information
