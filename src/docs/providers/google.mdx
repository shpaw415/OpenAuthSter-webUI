# Google OAuth2 Setup

Configure Google OAuth2 to allow users to sign in with their Google accounts.

## Setup Steps

1. Go to the [Google Cloud Console](https://console.cloud.google.com)
2. Create a new project or select an existing one
3. Navigate to **APIs & Services** > **Credentials**
4. Click **Create Credentials** > **OAuth client ID**
5. Select **Web application** as the application type
6. Add your authorized redirect URI: <props.RedirectURI value={props.redirectURI} />
7. Copy the **Client ID** and **Client Secret**

## Configuration Fields

| Field                       | Required | Description                                               |
| --------------------------- | -------- | --------------------------------------------------------- |
| Client ID                   | Yes      | The OAuth 2.0 client ID from Google Cloud Console         |
| Client Secret               | Yes      | The OAuth 2.0 client secret from Google Cloud Console     |
| Scopes                      | No       | Additional OAuth scopes (default: email) |
| PKCE                        | No       | Enable PKCE for enhanced security                         |
| Additional Query Parameters | No       | Extra parameters to include in the authorization URL      |

## PKCE Support

PKCE (Proof Key for Code Exchange) adds an additional layer of security for OAuth flows. Google supports PKCE and it's recommended to enable it.

## Additional Query Parameters

Common parameters you might want to add:

| Parameter     | Description                                                  |
| ------------- | ------------------------------------------------------------ |
| `prompt`      | Control consent screen (`none`, `consent`, `select_account`) |
| `login_hint`  | Pre-fill the email field                                     |
| `hd`          | Restrict to a specific Google Workspace domain               |
| `access_type` | Set to `offline` for refresh tokens                          |

## Recommended Scopes

- `email` - Access to user's email address
- `profile` - Access to user's basic profile information
- `openid` - Required for OpenID Connect
