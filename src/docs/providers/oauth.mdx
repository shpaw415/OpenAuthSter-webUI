# Custom OAuth2 Provider Setup

Configure a custom OAuth2 provider for authentication.

## Setup Steps

1. Obtain the **Authorization Endpoint** URL from your provider
2. Obtain the **Token Endpoint** URL
3. (Optional) Get the **JWKS Endpoint** for token verification
4. Register your application to get **Client ID** and **Client Secret**
5. Configure the appropriate **scopes** for your use case

## Configuration Fields

| Field                       | Required | Description                                          |
| --------------------------- | -------- | ---------------------------------------------------- |
| Client ID                   | Yes      | The OAuth client ID                                  |
| Client Secret               | Yes      | The OAuth client secret                              |
| Authorization Endpoint      | Yes      | URL for user authorization                           |
| Token Endpoint              | Yes      | URL to exchange code for tokens                      |
| JWKS Endpoint               | Yes      | URL for JSON Web Key Set (for token verification)    |
| Scopes                      | No       | OAuth scopes to request (default: email)             |
| Additional Query Parameters | No       | Extra parameters to include in the authorization URL |

## Additional Query Parameters

Some OAuth providers require or support additional query parameters. Add them as key-value pairs to customize the authorization request. Common examples include:

| Parameter | Description                                     |
| --------- | ----------------------------------------------- |
| `prompt`  | Control consent/login behavior                  |
| `state`   | Custom state parameter (usually auto-generated) |
| `nonce`   | Security token for replay protection            |

## OAuth2 Flow

1. User is redirected to the Authorization Endpoint
2. User authenticates and authorizes your application
3. Provider redirects back with an authorization code
4. Your server exchanges the code for tokens at the Token Endpoint
