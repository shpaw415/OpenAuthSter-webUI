# Twitch OAuth Setup

Configure Twitch OAuth to allow users to sign in with their Twitch accounts.

## Setup Steps

1. Go to the [Twitch Developer Console](https://dev.twitch.tv/console/apps)
2. Click **Register Your Application**
3. Fill in your application details:
   - **Name**: Your application name
   - **OAuth Redirect URLs**: Your callback URL (e.g., `https://your-domain.com/twitch/callback`)
   - **Category**: Choose the appropriate category
4. Click **Create**
5. Click **Manage** on your app to get the **Client ID**
6. Click **New Secret** to generate and copy your **Client Secret**

## Configuration Fields

| Field                       | Required | Description                                          |
| --------------------------- | -------- | ---------------------------------------------------- |
| Client ID                   | Yes      | The Client ID from Twitch Developer Console          |
| Client Secret               | Yes      | The Client Secret from Twitch Developer Console      |
| Scopes                      | No       | OAuth scopes to request (default: user:read:email)   |
| PKCE                        | No       | Enable PKCE for enhanced security                    |
| Additional Query Parameters | No       | Extra parameters to include in the authorization URL |

## PKCE Support

Twitch supports PKCE (Proof Key for Code Exchange). Enable it for enhanced security in your OAuth flow.

## Additional Query Parameters

Common parameters you might want to add:

| Parameter      | Description                                                           |
| -------------- | --------------------------------------------------------------------- |
| `force_verify` | Force re-authorization even if previously authorized (`true`/`false`) |

## Recommended Scopes

- `user:read:email` - Access to user's email address
- `openid` - Required for OpenID Connect
