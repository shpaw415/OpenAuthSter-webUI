# X (Twitter) OAuth Setup

Configure X (formerly Twitter) OAuth to allow users to sign in with their X accounts.

## Setup Steps

1. Go to the [X Developer Portal](https://developer.x.com/en/portal/dashboard)
2. Create a new Project and App (or select an existing one)
3. Navigate to your app's **Settings**
4. Under **User authentication settings**, click **Set up**
5. Configure OAuth 2.0 settings:
   - **Type of App**: Web App
   - **Callback URI**: Your redirect URL (e.g., `https://your-domain.com/x/callback`)
   - **Website URL**: Your application's URL
6. Save and copy your **Client ID** and **Client Secret**

## Configuration Fields

| Field                       | Required | Description                                               |
| --------------------------- | -------- | --------------------------------------------------------- |
| Client ID                   | Yes      | The OAuth 2.0 Client ID from X Developer Portal           |
| Client Secret               | Yes      | The OAuth 2.0 Client Secret from X Developer Portal       |
| Scopes                      | No       | OAuth scopes to request (default: users.read, tweet.read) |
| PKCE                        | No       | Enable PKCE for enhanced security                         |
| Additional Query Parameters | No       | Extra parameters to include in the authorization URL      |

## PKCE Support

X requires PKCE (Proof Key for Code Exchange) for OAuth 2.0. It should be enabled for all X OAuth flows.

## Recommended Scopes

- `users.read` - Access to user's account information
- `tweet.read` - Read access to tweets (required for authentication)
- `offline.access` - For refresh tokens

## Access Levels

X offers different access levels with varying rate limits and features:

| Level      | Description                        |
| ---------- | ---------------------------------- |
| Free       | Basic read-only access             |
| Basic      | Read and write with higher limits  |
| Pro        | Full API access for professionals  |
| Enterprise | Highest tier with custom solutions |
